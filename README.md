# tal-cars - "מצב מפלצת" לטל

עמוד יחיד, self-contained (בלי תמונות/CDN), עברית RTL, מותאם נייד.
נבנה 18/08/2026 אחרי שטל שלח סרטון על המכונית הכי מהירה.

**חי:** https://yossisamia-bot.github.io/tal-cars/
**Repo:** yossisamia-bot/tal-cars (public, GitHub Pages מ-master, שורש)

## מבנה
כל התוכן במערך `ITEMS` בתוך `index.html`. שלושה סוגי כרטיסים:
- `quiz` - שאלה עם תשובה נכונה (`correct` = אינדקס). 10 נק' נכון, 3 נק' טעות.
- `fact` - עובדה מטורפת + כפתור "קלטתי". 5 נק'.
- `pick` - בחירה בלי תשובה נכונה (צבע רכב, איזה מותג וכו'). 5 נק'.
`bmw:true` צובע את הכרטיס בכחול BMW.

הספירה, המקסימום (`MAX`) ודרגות הסיום מחושבים אוטומטית מ-`ITEMS` - להוסיף/להוריד פריטים
בלי לגעת בשום מספר אחר. נכון ל-18/08: 17 פריטים, 130 נק' מקסימום.

- המהירה בעולם: Yangwang U9 Xtreme, 496.22 קמ"ש, ATP Papenburg, 14/09/2025 (הורידה את Bugatti Chiron SS 300+).
