# tal-cars - "Monster Mode" לטל

עמוד יחיד, self-contained (תמונות מקומיות, בלי CDN), **אנגלית** - טל קורא רק אנגלית
(מדבר ושומע עברית, ולכן רק חתימה קטנה בעברית בתחתית). מותאם נייד.
נבנה 18/08/2026 אחרי שטל שלח סרטון על המכונית הכי מהירה.

**חי:** https://yossisamia-bot.github.io/tal-cars/
**Repo:** yossisamia-bot/tal-cars (public, GitHub Pages מ-master, שורש)

## ⭐ שינוי-כיוון 18/08 - מחידון למשחק
**המשוב מהמבחן האמיתי:** טל אמר "נחמד", **הפסיק באמצע**, ואז אמר שלא מעניין.
האבחנה: לולאת שאלה -> תשובה -> טקסט היא **קריאה פסיבית**. ילד בן 8.5 רוצה לעשות משהו
עם האגודל, ולקבל תוצאה מיידית שאפשר לשפר.

לכן העמוד נבנה מחדש כ-**6 מיני-משחקים**, מסך אחד בכל פעם (בלי גלילה ארוכה),
והעובדה הפכה ל**פרס קצר אחרי הניצחון** - לא טקסט שצריך לקרוא לפני.

## עקרון-על
**טל לא יודע כלום על מכוניות.** אף משחק לא דורש ידע מוקדם - הכל רפלקסים, קצב, דיוק
או התאמה חזותית. העובדה מגיעה רק כפרס, שורה-שתיים, ותמיד קושרת את מה שהוא בדיוק עשה
למשהו אמיתי ("עשית 2.99 שניות - צוות F1 אמיתי עושה את זה ב-2 שניות עם 20 אנשים").

## ששת המשחקים (`LEVELS` ב-`index.html`)
1. **🚦 START LIGHTS** - חמישה אורות אדומים נכבים, לוחצים מהר ככל האפשר. מודד ms.
   השוואה לנהג F1 (~200ms). זינוק מוקדם = jump start.
2. **🏁 DRAG RACE** - מקישים על הדוושה 6 שניות. 60 הקשות = תיקו מול הבוגאטי.
3. **🔍 EXTREME ZOOM** - קטע מוגדל מאוד מתמונת רכב + 3 תמונות, לבחור מאיזו הוא נחתך.
   4 סבבים. ההגדלה נעשית ב-CSS (`background-size:420%`) - בלי קבצי-קרופ נוספים.
4. **🔧 PIT STOP** - ארבעה גלגלים נדלקים בתורם, מקישים על כל אחד. מדידת זמן.
5. **🎯 HIT 420** - מחוג סוחף על מד-מהירות, לעצור בטווח הירוק (390-450 קמ"ש). 3 ניסיונות.
6. **🚧 DODGE** - שלושה נתיבים, קונוסים יורדים, מתמרנים 25 שניות. המהירות עולה עם הזמן.

**בכל מסך-תוצאה שני כפתורים: `NEXT` ו-`🔄 TRY THIS ONE AGAIN`** (מחזיר את הנקודות
ומריץ מחדש). זה מה שהופך את זה למשחק חוזר - "לשפר את השיא" - ולא למסלול חד-פעמי.
השיא נשמר ב-`localStorage` תחת `talBest` ומוצג במסך הפתיחה.

## מבנה טכני
`LEVELS` = מערך של פונקציות. כל פונקציה מציירת מסך ובסוף קוראת
`result(title, big, mini, rewardHtml, pts)` - שמוסיף ניקוד, מציג את הפרס ומרכיב
את שני הכפתורים. הוספת משחק = פונקציה חדשה + שורה במערך; הנקודות במעלה המסך
(`#dots`) נגזרות אוטומטית מאורך המערך.

דרגות סיום: 520+ WORLD CHAMPION / 420+ RACE DRIVER / 300+ MONSTER MODE / אחרת MECHANIC IN TRAINING.

בסוף: שני לינקים למשחקי מכוניות בדפדפן (חינם, בלי הורדה, עובד בנייד) -
[Slow Roads](https://slowroads.io/) (נהיגה אינסופית רגועה) ו-[Smash Karts](https://smashkarts.io/) (קארטינג, בסגנון מריו קארט).

## תמונות
`img\` - 12 תמונות מ-Wikimedia Commons (רישיונות חופשיים), 900px, הורדו מקומית כדי שהעמוד
יהיה עצמאי ומהיר. **כל תמונה נבדקה חזותית** שהיא באמת מה שכתוב עליה - תמונה שגויה
במשחק ההתאמה = באג. כולן נטענות מראש ב-`new Image()` בפתיחה, כדי שה-ZOOM לא יקפוץ.

## עובדות - מקורות שאומתו
- לוגו BMW = צבעי דגל בוואריה, **לא** מדחף. המיתוס נולד בפרסומת של BMW ב-1929; החברה הודתה רשמית ב-2020.
- Bugatti Chiron מוגבלת אלקטרונית ל-420 קמ"ש (מגבלת צמיגים).
- Isetta (1955) - הצילה את BMW מפשיטת רגל; כל החזית נפתחת.
- צמיג מונסטר-טראק ~1.7 מ' גובה.
- Tesla Model S Plaid ~2 שניות ל-100 קמ"ש, מנצחת פרארי מהעמידה.
- Porsche 911 - מנוע מאחור מאז 1963.
- DRS ב-F1 = "פטריית מריו קארט" אמיתית, מותר רק באזורים מסומנים.
- Rolls-Royce ו-Mini בבעלות BMW.
- Koenigsegg ~3 מיליון דולר; יעד 500 קמ"ש **טרם הושג** (מנוסח כך בכוונה).
- זמן תגובה של נהג F1 לכיבוי האורות ~200ms (מבוגר ממוצע ~350ms). זינוק מוקדם = 5 שניות עונש.
- החלפת ארבעה גלגלים ב-F1 ~2 שניות, עם ~20 אנשי צוות שלכל אחד תפקיד יחיד.
- Target fixation - נוהגים לאן שמסתכלים; מסתכלים על המכשול ונכנסים בו. תופעה מתועדת.

**הערה:** הרשימה כאן רחבה מהעובדות שבעמוד כרגע - חלקן נשארו מהגרסה הקודמת (החידון)
ומחכות לשימוש חוזר. הן אומתו ולכן נשמרות.

**כלל:** לא מוסיפים לכאן עובדה בלי מקור. ילד מספר את זה בכיתה.
